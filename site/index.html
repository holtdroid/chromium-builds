INSTALL

        
Three commands

        
On an Android emulator, a redroid container or a phone with USB debugging.

      

      
    
        
  1. Install the browser
    It installs as org.chromium.chrome, next to Chrome.
    
          
    SHELL
    $ adb install chromium-120.0.6099.231-x86_64.apk
    2. 
        
  2. Switch the WebView
    On AOSP images, redroid or rooted devices.
    
          
    SHELL
    $ adb install webview-120.0.6099.231-x86_64.apk
$ adb shell cmd webviewupdate \
    set-webview-implementation com.android.webview
    3. 
        
  3. Open DevTools
    Then chrome://inspect in desktop Chrome.
    
          
    SHELL
    $ adb shell am start -a android.intent.action.VIEW \
    -d https://example.com org.chromium.chrome
    4.

NOTES

        
Questions

      

      

        
Where can I get an old Chrome APK?
Google Play installs only the newest Chrome. Chromium of the same milestone renders pages and runs JavaScript the same way.

        
Which WebView did Android 11 ship with?
Its AOSP images ship WebView 83, the oldest milestone here: 83.0.4103.106.

        
Why does the WebView refuse to install?
Google APIs and Google Play emulator images accept only Google's signed WebView. Use an AOSP image, redroid or a rooted device.

        
x86_64 or arm64?
x86_64 for emulators on a PC and for redroid, arm64 for phones and for emulators on Apple Silicon.

        
Are the builds modified?
No. They come from Chromium's release tags without patches; only build arguments change. Every build log is public on GitHub Actions.

        
How fast do new versions appear?
A daily run picks up new Stable patches of the two newest milestones and the newest Beta. A build takes about half a day.
