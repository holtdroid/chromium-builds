INSTALL

Install Chromium 93 on an emulator or a phone

The WebView installs on AOSP emulator images, redroid and rooted devices. Google APIs and Google Play images accept only Google's signed WebView.

SHELL · X86_64
$ adb install chromium-93.0.4577.82-x86_64.apk
$ adb install webview-93.0.4577.82-x86_64.apk
$ adb shell cmd webviewupdate \
    set-webview-implementation com.android.webview
